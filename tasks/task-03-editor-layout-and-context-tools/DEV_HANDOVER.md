## 2. Реализованная функциональность (DoD)

### 2.1. Компоновка страницы и брендинг
- **Фон страницы**: спокойный светло-серый `#f4f5f7` (в темной теме `#111315`).
- **Центральный блок редактора**: выделенный белый блок `#ffffff` (в темной теме `#1a1d21`) с тонкой рамкой, скруглением (`border-radius: 12px`) и мягкой тенью.
- **Ширина центрального блока**: 840 px (в пределах требования 800–880 px).
- **Внутренние горизонтальные отступы**: 48 px (в пределах требования 40–56 px).
- **Единая левая граница**: заголовок статьи H1 (`#article-title`) и тело статьи (`.ql-editor`) имеют `padding: 0` внутри карточки редактора и выровнены по строго одинаковой координате левого края.
- **Симметричные боковые зоны**: 3-колоночный CSS Grid-лейаут (`.app-main-layout`) с боковыми зонами (`.side-zone-left` и `.side-zone-right`, 240–280 px на 1920px), удерживающий редактор строго по центру без паразитных сдвигов.
- **Адаптивность**: при сжатии экрана боковые зоны плавно схлопываются, отступы пропорционально уменьшаются, горизонтальный скролл отсутствует на любых разрешениях.

### 2.2. Удаление постоянного тулбара и новая компоновка панелей
- Широкая фиксированная полоса форматирования под шапкой полностью удалена.
- **Компактная верхняя панель (Header)**:
  - Логотип и брендинг `Antigravity Writer`.
  - Кнопка «📁 Черновики» с живым бейджем количества черновиков (`#drafts-badge`).
  - Статус автосохранения («Все изменения сохранены» / «Сохранение...»).
  - Переключатель режимов: «Редактирование» / «Предпросмотр» (`Edit` / `Preview`). В режиме предпросмотра редактор блокируется от редактирования, скрываются служебные маркеры и инсертеры, а инлайн-спойлеры становятся интерактивными.
  - Выпадающее меню «📤 Экспорт / Импорт» (HTML, Markdown, JSON, импорт из JSON).
  - Меню дополнительных действий (переключение темы, список горячих клавиш, полная очистка статьи).
- **Нижняя строка состояния (Status Bar)**:
  - Компактные кнопки Undo / Redo (`Ctrl+Z`, `Ctrl+Y`).
  - Статистика в реальном времени: количество слов, количество символов, расчетное время чтения.

### 2.3. Контекстная панель выделенного текста (Bubble Toolbar)
- Появляется **только** при непустом выделении текста (мышью или с клавиатуры) и автоматически скрывается при снятии выделения.
- Позиционируется над выделением (или под ним при нехватке места сверху у границы окна) с контролем границ viewport.
- **11 обязательных инструментов строго в заданном порядке**:
  1. **Жирный** (`data-format="bold"`)
  2. **Курсив** (`data-format="italic"`)
  3. **Подчеркнутый** (`data-format="underline"`)
  4. **Зачеркнутый** (`data-format="strike"`)
  5. **Подстрочный** (`data-format="script"` `data-value="sub"`)
  6. **Надстрочный** (`data-format="script"` `data-value="super"`)
  7. **Скрытый текст** (`data-format="inline-spoiler"`: инлайн-спойлер, редактируемый в редакторе и открываемый по клику в предпросмотре)
  8. **Без форматирования** (`data-action="clear-format"`: снятие стилей с сохранением текста)
  9. **Встроенный код** (`data-format="code"`)
  10. **Ссылка** (`data-action="link"`: модальный диалог с сохранением диапазона)
  11. **Формула** (`data-action="formula"`: диалог встроенной LaTeX-формулы с подстановкой выделенного текста)
- Единый стиль чистых SVG-иконок, разделители групп, русскоязычные подсказки.
- Активные форматы подсвечиваются (`is-active`).
- Клик по кнопкам не сбрасывает выделение текста (`mousedown preventDefault`), что позволяет применять несколько стилей последовательно.
- Клавиша `Escape` закрывает панель.
- Выпадающее меню «Еще ▾» внутри баббла:
  - Палитра цветов текста + кнопка сброса.
  - Палитра цветов фона (маркер выделения) + кнопка сброса.
  - Кнопки выравнивания текста (по левому краю, по центру, по правому краю, по ширине).

### 2.4. Плавающее меню добавления блока «+»
- Кнопка «+» привязана к текущей строке/каретке слева от редактора.
- Клавиатурная навигация: стрелки `Вверх` / `Вниз`, выбор по `Enter`, закрытие по `Escape`.
- Слэш-команда: ввод символа `/` в пустой строке автоматически открывает меню добавления блоков.
- **12 блоков строго в заданном порядке**:
  1. **Заголовок**: подменю с выбором H2, H3, H4.
  2. **Цитата**: стилизованный многострочный блок `blockquote`.
  3. **Список**: маркированный список `ul`.
  4. **Нумерованный список**: упорядоченный список `ol`.
  5. **Медиаэлемент**: встроенный видеоплеер (YouTube, Shorts, Vimeo, VK Video, VK iframe) с парсингом URL, безопасным iframe и fallback-ссылкой.
  6. **Изображение**: загрузка файла через FileReader (100% offline DataURL), вставка по URL, подпись `figcaption`, `alt`, выравнивание.
  7. **Разделитель**: горизонтальная линия `<hr>`.
  8. **Код**: многострочный блок кода с синтаксической подсветкой Highlight.js.
  9. **Формула**: блочная LaTeX-формула с предпросмотром и возможностью повторного редактирования по клику на формулу или кнопку «✎ Изменить».
  10. **Спойлер**: раскрывающийся блок `<details><summary>` с заголовком и телом.
  11. **Якорь**: именованный маркер `anchor` с валидацией уникальности ID по всей статье.
  12. **Персона**: карточка автора/эксперта (аватар/фото, имя, роль/должность, ссылка на профиль).
- **Группа «Дополнительно»**:
  - **Таблица**: создание интерактивной таблицы с контекстной панелью добавления/удаления строк и столбцов.
  - **Чек-лист**: интерактивный список задач с чекбоксами (`list: check`).
- При вставке блока пустая вспомогательная строка не дублируется, курсор корректно позиционируется.

### 2.5. Сохранение данных, совместимость и экспорт
- Хранилище IndexedDB со схемой `antigravity-editor-v2` и обратной совместимостью с v1.
- Автоматический подсчет количества черновиков с отображением в бейдже шапки.
- Экспорт в чистый HTML со стилями для кастомных блоков.
- Экспорт в GitHub Flavored Markdown (поддержка формул `$latex$` и `$$latex$$`, спойлеров `||text||` и `<details>`, якорей, карточек персон, таблиц и чек-листов).
- Формирование уведомлений (loss warnings) о несовместимости/упрощении кастомных блоков при экспорте в Markdown и HTML с отображением баннера в модальном окне.
- Экспорт в JSON со схемой `antigravity-editor-v2` и метаданными.
- Клиентская санитизация от XSS: удаление опасных тегов и атрибутов, разрешение `iframe` только для доверенных видеохостингов (YouTube, Vimeo, VK Video) с обязательной установкой безопасного атрибута `sandbox`.

### 2.6. Исправление замечания QA (Sandbox Security Fix)
По результатам QA-аудита (`tasks/task-03-editor-layout-and-context-tools/QA_REVIEW.md`) устранено замечание об отсутствии атрибута `sandbox` у элементов `iframe`:
1. **`frontend/public/js/core.js`**:
   - В фабричный метод `MediaEmbedBlot.create()` добавлена установка обязательного безопасного атрибута:
     `iframe.setAttribute('sandbox', 'allow-scripts allow-same-origin allow-presentation allow-popups');`
   - Зарегистрированы алиасы `window.VideoEmbed = MediaEmbedBlot` и `window.VideoBlot = MediaEmbedBlot`.
   - Добавлено безопасное переопределение стандартного формата `video` в Quill (`SafeVideoBlot`) с гарантированной установкой этого же атрибута `sandbox`.
2. **`frontend/public/js/converter.js`**:
   - В методе `sanitizeHTML()` при проверке разрешенных видеохостингов для прошедших валидацию iframe гарантированно устанавливается:
     `iframe.setAttribute('sandbox', 'allow-scripts allow-same-origin allow-presentation allow-popups');`
   - При экспорте в HTML (`exportToHTML`) и импорте JSON все видеоэлементы сохраняют строгую изоляцию.
3. **`frontend/public/js/media.js`**:
   - Добавлена константа спецификации `MediaManager.SAFE_IFRAME_SANDBOX = 'allow-scripts allow-same-origin allow-presentation allow-popups'`.
4. **`tests/test_editor_v3.py`**:
   - Добавлен тест `test_video_embed_iframe_contains_sandbox_attribute` для проверки наличия `sandbox` в `core.js`.
   - Добавлен тест `test_converter_js_enforces_sandbox_on_allowed_iframes` для проверки принудительной установки `sandbox` в `converter.js`.
   - Обновлен тест `test_allow_whitelisted_video_iframes` с проверкой корректного добавления sandbox-изоляции при санитизации.
