# Task: task-03-editor-layout-and-context-tools — Редизайн компоновки, контекстная панель и расширенные блоки

- **Цель**: Реорганизовать компоновку редактора (центрированный белый блок 800-880px на светло-сером фоне с боковыми зонами), убрать постоянную полосу инструментов под шапкой, перенести форматирование в 11-инструментный контекстный Bubble Toolbar, а добавление блоков — в 12-пунктовое меню «+» с поддержкой расширенных блоков (медиаэлементы YouTube/Vimeo/VK, формулы LaTeX, якоря, карточка персоны, спойлеры, код).
- **Границы изменений**:
  - Разрешено изменять/создавать:
    - `frontend/public/**` (HTML, CSS, JS модули редактора)
    - `tasks/task-03-editor-layout-and-context-tools/**`
    - `tests/**` (тестовый набор для валидации компоновки, инструментов и блоков)
  - Запрещено изменять:
    - `.agents/**`
    - `AGENTS.md`
- **Критерии приемки (DoD)**:
  1. **Компоновка страницы**:
     - Светло-серый фон страницы (`#f4f5f7` / темная тема `#121417`).
     - Выделенный белый центральный блок редактора (ширина 800–880 px, отступы 40–56 px).
     - Единая левая граница заголовка H1 и текста статьи.
     - Симметричные свободные боковые зоны (240–280 px каждая на 1920px) без сдвига центрального блока.
     - Адаптивное схлопывание боковых зон на планшетах/мобильных, отсутствие горизонтального скролла.
  2. **Компактная верхняя панель (без постоянной полосы форматирования)**:
     - Постоянная широкая полоса форматирования под шапкой полностью удалена.
     - В верхней панели: список черновиков, статус сохранения, предпросмотр (редактирование/просмотр), меню импорта/экспорта, меню действий (тема, очистка).
     - Счетчики слов, символов и времени чтения перенесены в ненавязчивую нижнюю строку состояния (Status Bar).
     - Undo/Redo доступны по `Ctrl+Z` / `Ctrl+Y` и кнопками в интерфейсе.
  3. **Контекстная панель выделенного текста (Bubble Toolbar)**:
     - Появляется только при непустом выделении текста (мышью или клавиатурой), скрывается при снятии.
     - Размещение над выделением (или под ним при нехватке места сверху), не перекрывая текст.
     - 11 обязательных инструментов строго по порядку:
       1) Жирный, 2) Курсив, 3) Подчеркнутый, 4) Зачеркнутый, 5) Подстрочный, 6) Надстрочный,
       7) Скрытый текст (inline spoiler), 8) Без форматирования (очистка стилей с сохранением текста),
       9) Встроенный код, 10) Ссылка (диалог с сохранением выделения), 11) Встроенная формула (LaTeX).
     - Единый стиль иконок, русские подсказки, активные состояния подсвечены.
     - Меню «Еще» для цвета текста, фона и выравнивания.
     - Закрытие по Escape.
  4. **Меню добавления блока через «+»**:
     - Плавающая кнопка «+» привязана к позиции вставки (слева от активного пустого абзаца или между блоками).
     - Поддержка клавиатуры (стрелки, Enter, Escape) и открытие по команде `/` в пустом абзаце.
     - 12 основных пунктов меню строго по порядку:
       1) Заголовок (H2, H3, H4)
       2) Цитата (многострочная с абзацами)
       3) Список
       4) Нумерованный список
       5) Медиаэлемент (видео YouTube, Vimeo, VK Видео с безопасным iframe и fallback)
       6) Изображение (загрузка файла / URL, подпись, alt)
       7) Разделитель (`<hr>`)
       8) Код (многострочный блок с выбором языка и подсветкой)
       9) Формула (блочная формула LaTeX с превью и повторным редактированием)
       10) Спойлер (раскрывающийся `<details><summary>`)
       11) Якорь (именованный маркер id с проверкой уникальности, виден в редакторе, скрыт в предпросмотре)
       12) Персона (карточка человека: имя, фото, подпись/роль, ссылка)
     - Группа «Дополнительно»: Таблица, Чек-лист.
  5. **Сохранность данных и интеграция**:
     - Сохранение и восстановление документа в IndexedDB со всеми новыми типами блоков.
     - Экспорт в HTML, Markdown (с уведомлениями о несовместимых блоках), JSON.
     - Корректная работа истории Undo/Redo для всех новых блоков.
     - Клиентская санитизация от XSS.
  6. **Верификация**:
     - Автоматизированный набор тестов для проверки компоновки, баббла, 12 блоков, парсеров видео и экспорта.
