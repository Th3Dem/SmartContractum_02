# Task: task-30-feed-subnav-personalization-card-comments — Вторая панель меню, персонализация ленты, обновление карточек публикаций, переходы к статьям и система комментариев

- **Цель**:
  1. **Вторая панель меню ленты**:
     - Расположение элементов слева направо: «Написать» (левый край, акцентное действие) -> «Настройка ленты» -> «Фильтры» -> «Моя лента» -> компактное меню персональных разделов («Сохраненные») -> справа: группа поиска с полем и отдельной кнопкой с лупой.
     - Единственная кнопка «Фильтры» (без дублирования).
     - Постоянная фиксация (sticky) второй панели под основной шапкой при скролле.
     - Содержимое выровнено по общему контейнеру страницы (1360px).
  2. **Выдвижной блок «Настройка ленты»**:
     - Раскрывающаяся область непосредственно под второй панелью (над контентом ленты, а не центральное модальное окно).
     - Разделы: «Типы материалов», «Уровень сложности», «Подписки».
     - Действия: «Сохранить настройки», «Отмена» и закрытие по повторному клику без сохранения.
     - Взаимное исключение: открыт либо блок персональных настроек, либо блок обычных фильтров.
     - Корректное смещение контента вниз, ограничение высоты со скроллом на мобильных экранах.
  3. **Типы материалов**:
     - Независимые чекбоксы: «Статьи», «Посты», «Новости», «Вопросы».
     - Мультивыбор, по умолчанию выбраны все 4. Запрет отключения всех с подсказкой «Выберите хотя бы один тип материала».
     - Поле типа материала (`materialType` / `type`) в модели данных и API. Значение по умолчанию для существующих статей — `article` («Статья»).
     - Реальное влияние на выдачу материалов.
  4. **Уровень сложности**:
     - Мультивыбор: «Простой», «Средний», «Сложный», «Не указан».
     - Вариант «Любой уровень» по умолчанию (без ограничений).
     - При выборе конкретного набора материалы без указанной сложности включаются только при наличии пункта «Не указан».
  5. **Управление подписками в настройках**:
     - Подписки на авторов, категории (темы из каталога) и хэштеги (ключевые слова).
     - Поиск, отображение выбранных, добавление и удаление внутри настроек ленты с переиспользованием существующей системы подписок.
     - Синхронизация с контекстными подписками на сайте.
     - Сохранение настроек в аккаунте пользователя на сервере, восстановление после перезагрузки.
  6. **Поведение режима «Моя лента»**:
     - Отбор: опубликованные материалы, тип входит в выбранный набор, сложность входит в выбранный набор, соответствует ХОТЯ БЫ ОДНОЙ подписке (автор ИЛИ тема ИЛИ хэштег).
     - Дедупликация материалов, подходящих по нескольким подпискам.
     - Заметное активное состояние кнопки «Моя лента», повторный клик возвращает ко всем публикациям с поясняющей подсказкой.
     - Состояния пустоты:
       * Нет подписок: «Подпишитесь на авторов, темы или хэштеги, чтобы собрать свою ленту» + кнопка «Настроить ленту».
       * Есть подписки, но нет подходящих публикаций: отдельное сообщение с предложением изменить настройки или перейти ко всем публикациям.
     - Обновление ленты при сохранении настроек без скрытого переключения режима.
  7. **Обычные фильтры и гостевой режим**:
     - Обычные фильтры временно уточняют текущую выдачу, не перезаписывая сохраненные предпочтения.
     - Отражение состояния в URL (режим, поиск, фильтры, сортировка).
     - Гостям доступны просмотр, поиск и обычные фильтры; при клике на «Настройка ленты» или «Моя лента» предлагается вход.
  8. **Компактный раскрывающийся поиск**:
     - Расположен в правой части второй панели.
     - Начальная ширина 220–260 px, при фокусе/клике плавное расширение до 360–420 px (при наличии места).
     - Отдельная кнопка с лупой справа; Enter и клик по лупе запускают один и тот же поиск; кнопка очистки запроса.
     - Группа удерживает раскрытое состояние при фокусе на любом элементе группы (включая лупу).
     - Плейсхолдер: «По статьям, авторам, тегам».
  9. **Обновленная карточка публикации**:
     - Верх: аватар, имя автора, роль/подпись, заголовок, бейджи тем и формата, полноширинная обложка 39:22, описание, хэштеги.
     - Дата публикации перенесена вниз из строки автора.
     - Бейдж сложности перенесен вниз (опускается, если сложность не указана).
     - Нижняя часть в 2 компактные строки:
       1. Служебная строка: дата публикации, время чтения, сложность.
       2. Строка действий: лайк с количеством, комментарии с количеством, закладка и «Читать далее».
  10. **Полное удаление метки «Демонстрационный материал»** из карточек и предпросмотра.
  11. **Сохранение требований к обложке**:
      - 100% внутренней ширины карточки, 39:22, только авторский кадр, 0px пустоты при отсутствии/ошибке, zero site overlays.
  12. **Лайки**:
      - Сердечко и счетчик в карточке и в статье (`article.html`).
      - Переключение: первое нажатие ставит, повторное снимает. 1 лайк на публикацию на пользователя.
      - Серверное сохранение (`POST /api/articles/<id>/like`), синхронизация счетчиков, откат при ошибке, предложение входа гостю.
  13. **Кнопка «Читать далее» и полная публикация**:
      - Явная ссылка «Читать далее» и клик по заголовку открывают статью по стабильному URL (`article.html?id=...`).
      - Возврат в ленту сохраняет режим, фильтры и позицию прокрутки.
  14. **Переход к комментариям**:
      - Иконка комментариев с реальным счетчиком в карточке.
      - Клик открывает статью со скроллом к `#comments` с учетом высоты закрепленных шапок.
  15. **Добавление и отображение комментариев**:
      - Раздел комментариев на `article.html`: список с автором, датой, текстом; поле «Ваш комментарий», кнопка «Отправить».
      - Валидация: запрет пустого текста, лимит 5000 символов, анти-двойной клик, сохранение текста при ошибке, экранирование HTML.
      - Гости могут читать, отправка доступна авторизованным пользователям.
  16. **Тестовые комментарии**:
      - Инициализация 3 комментариев к одной демо-публикации от «Тестовый читатель 1», «Тестовый читатель 2», «Тестовый читатель 3».
      - Идемпотентность (без дубликатов при повторной инициализации).
  17. **Тестирование и приемка**:
      - Автоматизированные тесты серверной логики, персональной выборки, лайков, комментариев и сохраненных настроек.
      - 100% Offline-First, шрифт Onest, Zero Emojis.
