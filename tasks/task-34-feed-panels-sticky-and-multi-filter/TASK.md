# Task: task-34-feed-panels-sticky-and-multi-filter — Закрепление панелей ленты при прокрутке, множественный выбор форматов и аудиторий, единый дизайн выпадающих списков и UX-полировка

- **Цель**:
  1. [x] **Исправление закрепления панелей при прокрутке**:
     - Панели «Настройка ленты» (`#feedSettingsPanel`) и «Фильтры» (`#feedFiltersPanel`) открываются непосредственно под нижней границей второго уровня шапки (`.feed-subnav-bar`) при любой позиции прокрутки ленты.
     - Открытая панель позиционируется как закрепленный (`fixed`) немодальный слой поверх публикаций без модального затемнения фона и без блокировки прокрутки страницы.
     - При прокрутке ленты панель не уезжает вверх и не скрывается под шапкой; открытие панели не прокручивает страницу к началу.
     - Одновременно открыта только одна панель, переключение между ними происходит в том же закрепленном пространстве.
     - Содержимое выровнено по основному контейнеру сайта (1360px), фон непрозрачный с тонкой нижней границей или тенью.
  2. [x] **Высота панели и внутренняя прокрутка**:
     - Положение и максимальная доступная высота рассчитываются динамически по фактическим размерам шапок и окна браузера (`max-height: calc(100vh - var(--feed-header-total-height))`).
     - Три части панели: 1) заголовок и кнопка закрытия (`flex: 0 0 auto`), 2) прокручиваемое тело (`flex: 1 1 auto; overflow-y: auto; overscroll-behavior: contain`), 3) закрепленная нижняя область действий (`flex: 0 0 auto`).
     - Кнопки («Сохранить настройки», «Применить фильтры», «Отмена», «Сбросить») всегда доступны.
     - Короткая панель занимает высоту контента, длинная ограничивается доступным пространством под шапкой.
     - Прокрутка изолирована: `overscroll-behavior: contain` предотвращает прокрутку ленты при достижении границ панели.
  3. [x] **Множественный выбор форматов публикации**:
     - В разделе «Дополнительные параметры» одиночный селект заменен на множественный выбор из полного справочника `PublicationConfig.FORMATS`.
     - Поведение: 0 выбрано — «Все форматы», 1 — название, >1 — «Выбрано форматов: N».
     - Выбранные форматы отображаются под полем удаляемыми метками (чипами).
     - Выбор не закрывает список; повторный клик снимает выбор; кнопка «Очистить выбор» сбрасывает ограничения.
  4. [x] **Множественный выбор целевых аудиторий**:
     - В разделе «Дополнительные параметры» одиночный селект заменен на множественный выбор из `PublicationConfig.AUDIENCES`.
     - Поведение аналогично: «Все аудитории», «Выбрано аудиторий: N», удаляемые чипы под полем, поиск и очистка.
  5. [x] **Логика совместной фильтрации на клиенте и сервере**:
     - Несколько форматов объединяются через ИЛИ; несколько аудиторий — через ИЛИ; разные группы фильтров — через И.
     - Обновлена обработка параметров в `server.py` (`format`, `formats`, `audience`, `audiences`) и в `feed.js`.
     - Полная обратная совместимость со старыми ссылками с одним форматом/аудиторией.
     - Фильтрация применяется ко всей выборке на сервере и клиенте с пагинацией.
  6. [x] **Единый дизайн выпадающих списков**:
     - Общий компонент множественного выбора для тем, форматов и аудиторий.

     - Интеллектуальное открытие вниз или вверх в зависимости от доступного пространства, без перекрытия нижней панели действий.
     - Клавиатурное управление, Escape сначала закрывает выпадающий список с возвратом фокуса, а при повторном нажатии — закрывает панель.
