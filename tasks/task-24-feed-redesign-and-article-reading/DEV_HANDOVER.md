### 1.1. Редизайн страницы «Лента» (`feed.html`, `feed.css`, `feed.js`)
1. **Сетка и компоновка**:
   - Двухколоночная центрированная сетка (контейнер 1280px, правая колонка 300px, gap 28px).
   - Компактный верхний hero-блок: четкий заголовок «Лента публикаций», лаконичное описание «Разработка, безопасность и практика применения коммерческих смарт-контрактов» и кнопка «Написать» со ссылкой на `editor.html`.
   - Первые карточки публикаций видны сразу на первом экране десктопа без избыточного вертикального скролла.
   - Адаптивность: на мобильных экранах (<1024px, <768px) сетка перестраивается в 1 колонку, правый сайдбар аккуратно переносится вниз после списка статей.
2. **Поиск, темы и многоуровневая фильтрация**:
   - Строка полнотекстового поиска с векторной SVG-иконкой лупы, счетчиком найденных результатов и кнопкой быстрой очистки поля поиска (с дебаунсом 250мс).
   - Официальный справочник тем из конфигурации публикации (`PublicationConfig.TOPICS`): ключевые направления выведены в основную строку («Все темы», «Разработка смарт-контрактов», «Информационная безопасность», «Право и комплаенс», «Оракулы и доверенные данные», «Интеграции и API»), остальные темы открываются через выпадающее меню «Еще темы». Исключены произвольные темы вроде «Дизайн».
   - Дополнительные селекты фильтров: целевая аудитория (`AUDIENCES`), формат публикации (`FORMATS`), уровень сложности (`COMPLEXITIES`), сортировка по дате («Сначала новые», «Сначала старые»), фильтрация по периоду («За все время», «За месяц», «За неделю»).
   - Панель выбранных фильтров (чипы с крестиком для точечного удаления и общая кнопка «Сбросить все»).
   - Полная синхронизация состояния поиска, фильтров и пагинации с URL через `URLSearchParams` и `history.pushState` / `popstate`: корректное восстановление при перезагрузке страницы и навигации по истории браузера.
3. **Обновление карточек публикаций (`.feed-card`)**:
   - Метаданные автора (аватар с инициалами, имя автора, должность/роль, дата публикации).
   - Обложка статьи с фиксированными пропорциями 780:440 (`aspect-ratio: 780 / 440`), кадрирование `object-fit: cover` без деформации; карточки без обложки отображаются компактно без пустых заглушек.
   - Читаемый заголовок (22px десктоп, 19px мобильный) и лаконичный лид (2–3 строки с `-webkit-line-clamp`).
   - Бейджи метаданных: метка темы, формата и сложности (без вывода «Не указан»).
   - Ключевые слова: до 3–4 тегов, остальные через бейдж «+N».
   - Нижняя строка: реальное расчетное время чтения и интерактивная кнопка «В закладки».
   - Изоляция кликов (`stopPropagation`): клики по автору, тегам, фильтрам и закладке не вызывают случайного перехода к чтению статьи.

4. **Закладки (сохраненные публикации)**:

   - Вкладка «Сохраненные» в шапке ленты для быстрого просмотра сохраненных публикаций с фильтрацией по сохраненным `ids`.

### 1.2. Создание сценария чтения статей (`article.html`, `article.css`, `article.js`)
1. **Полноценная страница чтения**:
   - Доступна по стабильному URL `article.html?id=<id>` с поддержкой прямого открытия по ссылке и перезагрузки.
   - Единая верхняя шапка сайта `#appHeader` (логотип SmartContractum, навигация «Дом» и «Лента», переключатель темы `#btnThemeToggle`, кнопка «Вход» `#headerLoginBtn`).
2. **Панели действий и навигация**:
   - Верхняя панель: кнопка «В ленту» (`#btnBackToFeed`), кнопка «В закладки» (`#btnArticleBookmark`) и кнопка «Поделиться» (`#btnCopyLink`) с копированием постоянной ссылки и всплывающим уведомлением (Toast).
   - Нижняя панель действий: повторные кнопки возврата в ленту и сохранения в закладки в конце статьи.
3. **Метаданные и обложка**:
   - Бейджи категорий, формата и сложности.
   - Крупный типографический заголовок публикации и вводный лид.
   - Авторский блок: аватар, имя, должность/роль.
   - Дата публикации и точное расчетное время чтения.
   - Обложка статьи с правильным соотношением сторон 780:440.
4. **Интерактивное оглавление (TOC)**:
   - Автоматически формируется из заголовков статьи H2–H4 при их наличии.
   - Плавная прокрутка (`scrollIntoView({ behavior: 'smooth' })`) к соответствующим разделам при клике.
5. **Отображение содержимого и блоков редактора**:
   - Комфортная ширина текстовой колонки (`max-width: 760px`).
   - Поддержка всех типов блоков редактора:
     - Таблицы с горизонтальным скроллом внутри блока (`.table-scroll-wrap`);
     - Блоки исходного кода с подсветкой синтаксиса через локальный `highlight.min.js`;
     - Математические формулы KaTeX;
     - Цитаты с вертикальным акцентным маркером;
     - Интерактивные спойлеры (`<details class="editor-spoiler">`) с кликом для раскрытия;
     - Изображения с подписями.
6. **Состояние ошибки (404 / Material Not Found)**:
   - Аккуратное состояние ошибки при невалидном или неопубликованном материале с кнопкой возврата в ленту.

### 1.3. Серверная интеграция в `server.py`
1. **Эндпоинт `GET /api/articles`**:
   - Возвращает только утвержденные публикации со статусом `status = 'approved'`.
   - Поддержка параметров: `search`, `topic`, `audience`, `format`, `complexity`, `sort` (`newest`, `oldest`), `period` (`all`, `month`, `week`), `ids` (список ID через запятую для закладок), `limit`, `offset`.
   - Возвращает общее количество `total`, список отфильтрованных статей и агрегированные счетчики публикаций по темам `topicCounts`.
2. **Эндпоинт `GET /api/articles/<id>`**:
   - Возвращает полные данные публикации (метаданные, расчетное время чтения, полный HTML-контент, delta).
   - Возвращает `HTTP 404 Not Found` для неопубликованных (pending, rejected, draft) или несуществующих материалов.
3. **Сидирование утвержденных публикаций (`seed_approved_articles`)**:
   - Наполнение базы данных SQLite 4 качественными утвержденными статьями по профильным темам ПКСК (цифровой рубль, безопасность смарт-контрактов, оракулы и доверенные данные, правовые аспекты смарт-контрактов) при инициализации БД.
