## 2. Реализованная функциональность (DoD)

### 2.1. Правый интерактивный сайдбар (`.side-zone-right`)
Размещен в правой симметричной колонке `.side-zone-right` без сдвига центрального блока статьи (840px):
1. **Виджет «Типограф» (`#widget-typograph`)**:
   - Заголовок с иконкой и поясняющим текстом: *«После редактирования улучшает типографику текста: исправляет кавычки, тире и привязывает союзы/предлоги»*.
   - Интерактивная кнопка **«Оттипографить текст»** (`#btn-typograph`).
   - Модуль типографики (`frontend/public/js/typograph.js`):
     - Замена прямых кавычек `"` на русские «елочки» (`«...»`), а вложенных — на немецкие лапки (`„...“`).
     - Замена дефисов между словами с пробелами (` - ` и ` -- `) на длинное тире (` — `).
     - Привязка 1–2-буквенных союзов и предлогов (`и, в, на, с, по, к, не, за, от, из, у, о, об, ни, а, но, да` в любом регистре) к следующему слову через неразрывный пробел `\u00A0` (`&nbsp;`).
     - Замена троеточия `...` на типографское многоточие `…`.
     - Строгое сохранение без изменений блоков кода (`<pre>`, `<code>`, `.ql-syntax`, `.editor-code-block`), формул LaTeX (`$$...$$`, `\(...\)`, `.editor-block-formula`, `.editor-inline-formula`) и ссылок/URL (`<a>`, `href`, `https://...`).
     - Изменения применяются через Quill Delta со статусом `'user'`, что сохраняет историю и позволяет отменить операцию стандартным `Ctrl+Z`.
     - Всплывающее уведомление (toast): *«Текст статьи успешно оттипографилен»*.
     - Статус-индикатор выполнения типографики (`#typograph-status`).
2. **Виджет «Памятка автору» (`#widget-author-guide`)**:
   - Советы по структуре статьи (заголовок, лид, смысловые подзаголовки H2–H4, визуальные медиа, акцентное форматирование).
   - Быстрая шпаргалка по горячим клавишам: `/` для меню блоков, `Ctrl+K` для ссылок, `Ctrl+B/I/U`, `Ctrl+S` для сохранения, `Esc` для закрытия.
3. **Виджет «Чек-лист публикации» (`#widget-checklist`)**:
   - Живой динамический чек-лист с автоматическим обновлением при вводе текста:
     - `[x]/[ ]` Заголовок статьи заполнен (`#chk-title`);
     - `[x]/[ ]` Объем текста (> 100 слов) (`#chk-words`);
     - `[x]/[ ]` Наличие подзаголовков (H2-H4) (`#chk-headers`);
     - `[x]/[ ]` Типографика проверена (`#chk-typograph`).
   - Визуальный прогресс-бар готовности (`#checklist-progress-fill`).
   - Бейдж статуса (`#readiness-badge`): *«Готово к публикации»* (зеленый), *«Черновик (X/4)»* (желтый), *«Черновик (0/4)»*.
4. **Адаптивность**:
   - На экранах с шириной менее 1280px (`@media (max-width: 1280px)`) правый сайдбар скрывается (`display: none !important`), центральная карточка редактора остается аккуратно сцентрированной.

### 2.2. Поблочные элементы управления (Node Controls)
Реализован менеджер `NodeControlsManager` в `frontend/public/js/node-controls.js`:
- При наведении курсора мыши или фокусе на любой блок в Quill (`.ql-editor > *`):
  - **Слева**: ручка перетаскивания `node__drag-control` с иконкой `:::` (`draggable="true"`), поддерживающая HTML5 Drag & Drop для изменения порядка блоков.
  - **Визуальная направляющая вставки (`#node-drop-line`)**: синяя акцентная горизонтальная линия, показывающая, куда именно будет вставлен блок (выше или ниже целевого элемента).
  - **Справа**: кнопка трех точек `node__dots` (`...`), открывающая контекстное меню действий:
    - **«Преобразовать»**: выпадающее подменю для быстрой конвертации блока в:
      - Параграф (`¶`)
      - Заголовок H2 (`H2`)
      - Заголовок H3 (`H3`)
      - Цитату (`❝`)
      - Маркированный список (`•`)
    - **«Дублировать блок»**: создание точной копии блока сразу под текущим;
    - **«Удалить блок»**: безопасное удаление блока с сохранением в стеке Undo (`Ctrl+Z`).
- В режиме предпросмотра (`body.preview-mode`) контролы и направляющие скрываются.

### 2.3. Плавающее контекстное меню изображений (Image Menu)
Реализован менеджер `ImageMenuManager` в `frontend/public/js/node-controls.js`:
- При клике на любое изображение в редакторе прямо над ним появляется компактное плавающее меню (`#image-menu` / `.image-menu-container`):
  - Кнопка **«В тексте»** (`#btn-image-inline` / `data-test-id="toggle-float"`): стандартная ширина 100% текстовой колонки (`align-center`).
  - Кнопка **«Во всю ширину»** (`#btn-image-full` / `data-test-id="toggle-full"`): расширенная ширина карточки (`align-full`, вылет в поля карточки редактора).
  - Кнопка **«В рамку»** (`#btn-image-border` / `data-test-id="toggle-border"`): переключение стильной рамки вокруг изображения (`has-border`).
  - Кнопка **«Удалить»** (`#btn-image-delete` / `data-test-id="delete-image"`): удаление изображения из статьи.
  - Редактируемая подпись (`<figcaption contenteditable="true">`) под изображением для подписи источника или описания.
