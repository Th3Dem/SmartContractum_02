# Task: task-04-habr-tools-and-sidebar — Внедрение инструментов референса Хабра (Сайдбар, Типограф, Drag & Drop блоков, Меню изображений)

- **Цель**: Доработать редактор согласно анализу референса Хабра: добавить интерактивный правый сайдбар (виджеты «Типограф», «Памятка автору», «Чек-лист публикации»), поблочные элементы управления (ручка Drag & Drop `:::` слева и меню действий трех точек `...` справа от каждого блока), а также плавающее контекстное меню для изображений («В тексте», «Во всю ширину», «В рамку», «Удалить»).
- **Границы изменений**:
  - Разрешено изменять/создавать:
    - `frontend/public/**` (HTML, CSS, JS модули редактора)
    - `tasks/task-04-habr-tools-and-sidebar/**`
    - `tests/**` (тестовый набор для валидации типографа, сайдбара и контролов)
  - Запрещено изменять:
    - `.agents/**`
    - `AGENTS.md`
- **Критерии приемки (DoD)**:
  1. **Правый сайдбар (Вспомогательные виджеты автора)**:
     - Размещается в правой боковой зоне `.side-zone-right` без сдвига центрального редактора.
     - Виджет **«Типограф»**:
       - Кнопка «Оттипографить текст» с иконкой и пояснением.
       - Автоматическая обработка текста статьи: замена прямых кавычек `"` на русские «ёлочки» (и вложенные „лапки“), замена дефисов между словами на длинное тире `—`, привязка коротких предлогов/союзов через неразрывные пробелы `&nbsp;`, исправление троеточия `...` $\to$ `…`.
       - Индикатор успешной типографики и возможность отмены через Undo (`Ctrl+Z`).
     - Виджет **«Памятка автору»**:
       - Подсказки по структуре статьи (заголовок, лид, форматирование, списки).
       - Список горячих клавиш (`/` для меню блоков, `Ctrl+K` для ссылок, `Ctrl+B`, `Ctrl+I`, `Ctrl+S`, `Escape`).
     - Виджет **«Чек-лист готовности публикации»**:
       - Живой интерактивный индикатор готовности:
         - Заголовок статьи заполнен;
         - Объем текста (счетчик слов);
         - Наличие структуры (подзаголовки H2–H4);
         - Проверка типографики выполнена.
     - Адаптивность: на экранах менее 1280px сайдбар плавно сворачивается в компактную выезжающую панель или скрывается, не ломая верстку.
  2. **Поблочные элементы управления (Node Controls)**:
     - У каждого блока (абзац, заголовок, цитата, список, код, спойлер, таблица):
       - **Слева**: ручка Drag & Drop (`:::`) `node__drag-control` для захвата и перетаскивания блока вверх/вниз в документе с визуальной подсветкой целевой позиции (HTML5 Drag & Drop).
       - **Справа**: кнопка трех точек (`...`) `node__dots`, при клике на которую открывается выпадающее контекстное меню узла:
         - «Преобразовать» (Параграф, Заголовок H2, H3, H4, Цитата, Список);
         - «Дублировать блок» (создание точной копии блока сразу под текущим);
         - «Удалить блок» (`delete-node`).
  3. **Плавающее контекстное меню изображений (`Image Menu`)**:
     - При клике на любое изображение в статье прямо над ним появляется компактная панель:
       - «В тексте» (стандартная ширина 100% текстовой колонки);
       - «Во всю ширину» (расширенная ширина карточки);
       - «В рамку» (`toggle-border`: переключение стильного контура/бордера вокруг изображения);
       - «Удалить изображение».
     - Под изображением доступно поле редактирования подписи (`figcaption`).
  4. **Сохранность данных и интеграция**:
     - Все изменения и параметры блоков сохраняются в IndexedDB и отражаются в экспорте (HTML, Markdown, JSON).
     - Полная совместимость со всеми 45 тестами предыдущих этапов.
  5. **Тестирование**:
     - Автоматизированные тесты для проверки типографа, drag-and-drop атрибутов, меню трех точек и меню изображений.
