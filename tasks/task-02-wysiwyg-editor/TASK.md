# Task: task-02-wysiwyg-editor — Разработка автономного WYSIWYG-редактора с нуля

- **Цель**: Разработать с чистого листа полноценный, автономный модульный WYSIWYG-редактор для написания статей и постов (по референсу создания статей Хабра), готовый к будущей интеграции с бэкендом.
- **Границы изменений**:
  - Разрешено изменять/создавать:
    - `frontend/**` (или `public/**` для раздачи статики)
    - `tasks/task-02-wysiwyg-editor/**`
    - `tests/**` (тесты для фронтенд-редактора)
  - Запрещено изменять:
    - `.agents/**`
    - `AGENTS.md`
    - Запрещено копировать устаревший монолитный код из `Projects_01`
- **Критерии приемки (DoD)**:
  1. **Интерфейс и компоновка (по референсу Хабра)**:
     - Отдельное поле ввода заголовка статьи (H1).
     - Просторная рабочая область редактирования с комфортной шириной строки и чистой типографикой.
     - Закрепленная (sticky) верхняя панель инструментов форматирования.
     - Контекстное плавающее меню (bubble toolbar) при выделении текста.
     - Меню добавления новых блоков через плавающую кнопку «+».
  2. **Инструменты форматирования текста**:
     - Заголовки уровней H2, H3, H4.
     - Форматирование: жирный, курсив, подчеркивание, зачеркивание, цвет текста и цвет выделения (с возможностью сброса).
     - Верхний и нижний индексы (sub/sup), моноширинный инлайн-код (`code`).
     - Диалог добавления/редактирования/удаления ссылок.
     - Списки: нумерованный, маркированный, чек-листы (интерактивные списки задач), вложенные уровни отступов.
     - Блочные цитаты (blockquote) и разделители (`<hr>`).
     - Очистка форматирования, отмена/повтор (undo/redo).
  3. **Блочные элементы и медиа**:
     - Блоки кода с выбором языка программирования и подсветкой синтаксиса.
     - Интерактивные таблицы с возможностью добавления/удаления строк и столбцов.
     - Спойлеры / раскрывающиеся блоки (`<details><summary>`).
     - Вставка изображений (загрузка с диска через DataURL/IndexedDB и по прямой ссылке, подпись, альтернативный текст).
  4. **Сохранение и черновики**:
     - Автосохранение черновика в браузере (IndexedDB/LocalStorage) каждые несколько секунд и при изменении.
     - Индикатор статуса ("Сохранено", "Сохранение...").
     - Восстановление текста при случайном закрытии вкладки или перезагрузке страницы.
  5. **Импорт / Экспорт**:
     - Экспорт документа в HTML, Markdown и структурированный JSON.
     - Импорт структурированного документа.
  6. **Автономность (Offline-first)**:
     - 100% работа без интернета: все библиотеки (Quill / Highlight.js и др.) и стили размещены локально в папке `vendor/`, без внешних CDN-зависимостей.
  7. **Тестирование**:
     - Автоматизированные тесты для проверки структуры, сериализации/десериализации, санитизации HTML от XSS и сохранения черновиков.
