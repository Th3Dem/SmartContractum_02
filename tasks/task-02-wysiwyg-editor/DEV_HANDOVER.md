## 1. Обзор выполненной реализации

Разработан с чистого листа полноценный модульный WYSIWYG-редактор для создания статей и публикаций (по референсу редактора Хабра), полностью готовый к автономной работе и последующей интеграции с бэкендом.

### 1.1. Структура созданных файлов
```
frontend/public/
```

## 2. Реализованная функциональность (DoD)

1. **Компоновка и типографика (референс Хабра)**:
   - Отдельное поле ввода заголовка статьи (H1) с автоподгонкой высоты.
   - Комфортная ширина чтения статьи (820px) с чистой типографикой и интерлиньяжем 1.7.
   - Закрепленная (sticky) верхняя панель инструментов с группировкой действий.
   - Контекстная всплывающая панель (Bubble Toolbar) при выделении фрагмента текста.
   - Плавающая кнопка добавления блоков «+» с выпадающим меню быстрого выбора.
   - Светлая и темная темы оформления с сохранением предпочтения в localStorage.

2. **Форматирование текста**:
   - Заголовки H2, H3, H4 (H1 зарезервирован для заголовка статьи).
   - Жирный, курсив, подчеркивание, зачеркивание.
   - Палитра цветов текста и подсветки фона с кнопками мгновенного сброса.
   - Верхний и нижний индексы (`X²`, `X₂`), моноширинный инлайн-код (`<code>`).
   - Модальный диалог добавления, редактирования и удаления ссылок (`Ctrl+K`).
   - Маркированный и нумерованный списки, интерактивные чек-листы (`list: check`), отступы.
   - Блочные цитаты (`blockquote`) и горизонтальные разделители (`<hr>`).
   - Очистка форматирования, отмена и повтор действий (`undo`/`redo`, `Ctrl+Z`, `Ctrl+Y`).

3. **Блочные структуры и медиа**:
   - Блоки кода с подсветкой синтаксиса через Highlight.js и выбором языка.
   - Интерактивные таблицы: вставка произвольного размера, контекстная плавающая панель для добавления/удаления строк и столбцов.
   - Спойлеры / раскрывающиеся блоки (`<details><summary>`).
   - Изображения: 100% автономная загрузка файлов через `FileReader` (DataURL/Base64), прямые ссылки, подписи (`figcaption`), `alt`-текст, выравнивание, вставка через перетаскивание (drag & drop) и из буфера обмена (`Ctrl+V`).

4. **Автосохранение и черновики (IndexedDB)**:
   - Автосохранение черновика каждые 2 секунды после изменений с индикатором статуса («Сохранение...», «Все изменения сохранены»).
   - Модальное окно управления черновиками: список с датой, количеством слов и времени чтения, восстановление в один клик, удаление, создание новой статьи.
   - Автоматическое восстановление последнего черновика при перезагрузке страницы.
   - Горячая клавиша `Ctrl+S` для моментального сохранения с toast-уведомлением.

5. **Импорт / Экспорт и Безопасность**:
   - Экспорт в чистый HTML (автономный документ или фрагмент статьи).
   - Экспорт в GitHub Flavored Markdown (заголовки, стили, таблицы, чек-листы, код, спойлеры).
   - Экспорт в структурированный JSON со схемой `antigravity-editor-v1` и метаданными.
   - Импорт документа из JSON (через файл или текстовое поле).
   - Полная клиентская санитизация HTML от XSS-атак (удаление `<script>`, `<iframe>`, опасных атрибутов `on*`, псевдо-протоколов `javascript:`).

6. **100% Offline-First**:
   - Все библиотеки (`quill.js`, `highlight.min.js`, CSS) вендорированы локально в `frontend/public/vendor/`.
   - Ноль внешних обращений к CDN, Google Fonts или сторонним серверам.
