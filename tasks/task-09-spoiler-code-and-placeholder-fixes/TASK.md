# TASK-09: Доработка инлайн-спойлера (блюр по клику), блока кода (светлый фон и селектор языка) и блочного спойлера (динамический плейсхолдер)

## 1. Контекст и цели
Пользователь запросил устранение трех дефектов поведения и визуального оформления редактора:
1. **Инструмент «Скрытый текст (спойлер)» в меню выделения (Bubble Toolbar)**:
   - Ранее при нажатии ничего визуально не происходило (отсутствовал блюр текста).
   - Требуется: выделенный текст должен визуально блюриться (`filter: blur(...)`), а при клике мышью по заблюренному тексту блюр должен пропадать (раскрывать текст).
2. **Инструмент «Код» в меню «+»**:
   - Ранее блок кода имел темный мрачный фон (`#23241f` / `#1e293b`), а выпадающий список выбора языка программирования перекрывал текст первой строки кода.
   - Требуется: заменить фон на приятный лаконичный серый (`#f8f9fa` / `#f6f8fa`), стилизовать выпадающий список выбора языка в строгом минималистичном стиле дизайн-системы (шрифт Onest, аккуратная стрелочка, лаконичные границы) и аккуратно вынести его за пределы текстовой области блока (сверху справа над блоком), чтобы он не перекрывал строки кода.
3. **Инструмент «Спойлер» в меню «+»**:
   - Ранее текст заголовка и содержимого вставлялся как статичный текст (`Заголовок спойлера...`), который приходилось стирать вручную.
   - Требуется: сделать плейсхолдер аналогично главному верхнему заголовку H1 — серый текст-подсказка, который исчезает в момент ввода символов и появляется снова, если блок очищен.

---

## 2. Критерии приемки (Definition of Done)

### 2.1. Инлайн-спойлер в Bubble Toolbar
- [ ] При выборе текста и нажатии кнопки «Скрытый текст (спойлер)» (`data-format="inline-spoiler"`) текст оборачивается в `.editor-inline-spoiler`.
- [ ] По умолчанию `.editor-inline-spoiler` имеет визуальный блюр (`filter: blur(4.5px);`), легкую подложку, скругление и `cursor: pointer; user-select: none;`.
- [ ] При клике мышью по заблюренному тексту в редакторе (как в режиме редактирования, так и в режиме предпросмотра) класс `.is-revealed` переключается: блюр исчезает (`filter: none; user-select: text;`). Повторный клик возвращает блюр.
- [ ] Кнопка в Bubble Toolbar корректно подсвечивается в активном состоянии (`is-active`), когда курсор находится внутри инлайн-спойлера.

### 2.2. Блок кода и селектор языка программирования
- [ ] Фон блока кода (`.ql-snow .ql-editor .ql-code-block-container`, `.ql-editor pre.ql-syntax`) изменен с мрачного черного на спокойный светлый серый (`var(--code-bg, #f8f9fa)` в светлой теме).
- [ ] Текст кода контрастный и читаемый (`var(--code-text, #24292f)`), рамка аккуратная (`1px solid var(--code-border, #e2e8f0)`).
- [ ] Выпадающий список выбора языка программирования (`select.ql-ui`) аккуратно вынесен за пределы текстовой строки кода:
  - Позиционирован над правым верхним краем блока кода (`position: absolute; top: -26px; right: 0;`).
  - Для блока кода зарезервирован верхний отступ (`margin-top: 28px;` или `1.8em`), чтобы селектор не наезжал на вышестоящий контент.
- [ ] Селектор языка оформлен в минималистичном стиле сайта:
  - Шрифт: Onest (`font-family: 'Onest', sans-serif`).
  - Компактный размер: высота 22px, шрифт 11px, `font-weight: 500`.
  - Лаконичный фон (`var(--bg-hover)`), тонкая рамка (`var(--border-color)`), стрелочка chevron вниз через SVG.
  - Плавные состояния hover и focus.
  - Селектор никогда не перекрывает текст внутри блока кода.

### 2.3. Блочный спойлер с динамическим плейсхолдером
- [ ] При вставке спойлера из меню «+» создается блок спойлера без вшитого статичного текста: заголовок (`<summary>`) и тело (`<div class="editor-spoiler-body">`) инициализируются пустыми с атрибутами `data-placeholder="Заголовок спойлера"` и `data-placeholder="Скрытый текст спойлера..."`.
- [ ] Серый цвет плейсхолдеров соответствует `var(--text-placeholder)` (аналогично главному заголовку H1 `#article-title`).
- [ ] В момент ввода пользователем любого текста плейсхолдер автоматически исчезает.
- [ ] Если весь введенный текст удален, серый плейсхолдер снова отображается.
- [ ] Экспорт в Markdown (`converter.js`) корректно сохраняет введенные данные или стандартное наименование, если заголовок остался пустым.

### 2.4. Общие требования
- [ ] 100% Offline-First: отсутствие запросов к внешним CDN.
- [ ] Строгое соблюдение шрифта **Onest** во всех элементах.
- [ ] Разработан комплексный набор автоматических тестов `tests/test_spoiler_and_code_refinements.py`.
- [ ] Все ранее созданные и новые тесты проходят на 100% (`python3 -m unittest discover -s tests -p 'test_*.py'`).
