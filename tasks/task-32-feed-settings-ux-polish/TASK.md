- **Цель**:
  1. **Собрать управление подписками в едином блоке**:

       * «Публикации выбранных авторов, тем и хэштегов попадают в “Мою ленту”» (для подписок).
       * «Выбранные авторы, темы и хэштеги скрываются из общей и персональной ленты» (для исключений).
     - Строка с вкладками («Авторы», «Темы», «Хэштеги») со счетчиками выбранных элементов и кнопкой добавления справа («Добавить подписки» / «Добавить исключения», на мобильном допускается перенос).
     - Список выбранных элементов под вкладками.
  2. **Улучшить отображение подписок и исключений**:
     - Авторы: компонент аватара (как в карточке, с инициалами при отсутствии изображения), имя, короткое публичное описание, нейтральная вторичная кнопка «Отписаться» / «Убрать» с контрастным текстом и состояниями hover/focus.
     - Темы и хэштеги: компактные строки с названием и действием, корректный перенос длинных названий без наложения на кнопку.
     - Отсутствие растягивания одиночного элемента на всю ширину и пустого резервирования высоты под короткий список.
     - Сохранение каталога и пагинированного поиска (по 20 элементов). По умолчанию — показ собственных элементов пользователя.
  3. **Уточнить подписи в настройках**:
     - Удалить плашку «Минимум один» возле типов материалов. Подсказка: «Выберите хотя бы один тип материалов для “Моей ленты”».
     - Подсказка сложности: «Выберите подходящие уровни для “Моей ленты” или оставьте любой».
     - Единое именование «Без указанного уровня» в настройках и фильтрах.
     - Четкая индикация выбора (галочки и положение тумблеров помимо цвета).
  4. **Свернуть полный список тем в фильтрах**:
     - Заменить набор кнопок компактным полем «Выбрать темы» с поиском и множественным выбором.
     - Состояние по умолчанию: «Все темы».
     - При открытии: поиск и список с чекбоксами, ограничение высоты, прокрутка, мобильная адаптивность.
     - Выбор не закрывает список, поисковый запрос не скрывает выбранные элементы.
     - Выбранные темы отображаются под полем удаляемыми метками (chips); удаление последней возвращает «Все темы».
  5. **Очевидное отсутствие ограничений в фильтрах**:
     - Явные кнопки-состояния «Все типы» и «Любой уровень».
     - По умолчанию активно состояние без ограничений. Выбор конкретного значения снимает его; снятие всех возвращает «Все типы» / «Любой уровень».
     - Клик по «Все типы» или «Любой уровень» сбрасывает конкретный выбор.
     - В настройках сохраняется правило обязательного выбора хотя бы одного типа.
  6. **Доработать дополнительные параметры в фильтрах**:
     - 2 колонки с промежутком 16-24px на десктопе, 1 колонка на мобильном.
     - Единый размер и стиль подписей, одинаковая высота полей, видимый индикатор раскрытия.
     - Блок свернут по умолчанию, если параметры не выбраны. Если выбраны — развернут с бейджем количества активных ограничений на заголовке.
  7. **Сортировка в одном месте**:

     - Документированная сортировка по реальным метрикам (популярные/обсуждаемые).
     - Сброс фильтров не сбрасывает выбранную сортировку.
