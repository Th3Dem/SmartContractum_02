## Результаты выполнения
1. **Кнопка «Написать» во второй панели (`#feedSubnavBar`)**:
   - Выявлена корневая причина невидимости: в `.feed-subnav-write-btn` использовалась отсутствующая переменная `var(--color-primary)`.
   - Заменено на согласованный синий акцентный градиент `linear-gradient(135deg, #3861fb 0%, #2563eb 100%)` с белым цветом текста `#ffffff`.
   - Добавлены четкие состояния hover, active, focus-visible и поддержка светлой темы `[data-theme="light"]`.
   - Сохранена иконка пера (2px stroke) и доступная подпись «Написать», клик ведет в существующий сценарий создания статьи (`editor.html`).

2. **Загрузка обложек и пустая область карточки**:
   - Выявлена корневая причина ошибки первой обложки: неэкранированные спецсимволы `#` и кириллица в UTF-8 data-URI воспринимались браузером как фрагменты URL и ломали парсинг SVG.
   - Реализована функция `make_svg_data_uri` в `server.py` с гарантированным base64-кодированием (`data:image/svg+xml;base64,...`) для всех seed-статей и fallback-списка.
   - В CSS изолированы 4 состояния обложки:
     - Нет обложки: компактная карточка, 0px пустого пространства.
     - Загрузка: shimmer-анимация с пропорцией 780:440.
     - Загружена: плавное появление с `object-fit: cover`.
     - Ошибка загрузки: `onerror` мгновенно удаляет контейнер `.card-cover-container`, превращая карточку в чисто текстовую без значка ошибки и пустоты.

3. **Оформление блока «Темы» в боковой колонке**:
   - Устранено расхождение классов между CSS (`.widget-topic-row`) и JS (`.widget-topic-chip`).
   - Стилизованы строки: название слева с переносом слов, счетчик справа в аккуратной капсуле (`.widget-topic-count`).
   - Добавлены состояния hover, active (`.is-active`), focus-visible.
   - Реализована сортировка в списке: по убыванию количества опубликованных статей, затем по алфавиту на русском языке (`localeCompare('ru')`).
   - Кнопка «Показать все» раскрывает полный каталог тем без деформации верстки.

4. **Вторая панель управления и поиск**:
