# Правила проекта Projects_02

## 1. Типографика и дизайн
- **Шрифт проекта**: Для всех страниц, компонентов, редактора и любых новых модулей проекта везде и безусловно используется шрифт семейства **ONEST** (`--font-sans: 'Onest', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`).
- Использование любых других основных шрифтов запрещено, если нет прямого указания пользователя.
- Все файлы шрифта Onest вендорируются локально в `frontend/public/vendor/fonts/onest/` (принцип 100% offline-first).

## 2. Иконки и визуальный стиль
- **Векторные SVG-иконки**: Все элементы управления, меню и кнопки используют исключительно строгие технологичные векторные SVG-иконки (Flaticon / Lucide style, 2px stroke). Использование эмодзи в элементах интерфейса запрещено.
- **Строгий технологичный минимализм**: Лаконичные аккуратные кнопки (высота 32–34 px, скругление 8 px), выверенная модульная сетка, идеальное вертикальное и горизонтальное выравнивание.

## 3. Архитектура и ограничения
- **100% Offline-First**: Полное отсутствие внешних запросов к CDN в runtime. Все вендорные библиотеки и шрифты хранятся локально.
- **Чистая кодовая база**: Запрещено копировать монолитный устаревший код из `Projects_01`.

## 4. Единые компоненты и дизайн-токены
- **Правило единообразия интерфейса**: Однотипные элементы на всех страницах используют общие компоненты и дизайн-токены. Для одинаковых ролей должны совпадать шрифты, размеры, насыщенность, отступы, радиусы, обводки, иконки и цвета состояний. Стили отдельной страницы не должны менять общую шапку или другие глобальные компоненты.
- Это правило касается одинаковых по назначению элементов. Заголовок статьи, подпись поля и пункт меню могут иметь разные стили согласно общей типографической иерархии.
- Используйте общие переменные для типографики, цветов, радиусов и размеров элементов. Не создавайте отдельную несогласованную систему стилей для редактора.
